Giai đoạn 01 • Phần cứng & BIOS Dell

Cấu Hình BIOS Dell Inspiron i3 Gen 7 Chạy Bền Bỉ 24/7

⏱️ ~2 phút thủ công Nhấn F2 khi khởi động
1.1. Bật tự động khởi động lại khi có điện (AC Recovery)

Vào BIOS (F2) → Power Management → AC Recovery → chọn Power On. Server tự khởi động lại và chạy toàn bộ dịch vụ sau khi mất điện.

✓ Xác minh: Tắt máy, rút sạc rồi cắm lại — laptop tự sáng đèn boot lên là đạt.
1.2. Giới hạn sạc pin 50%–75% chống phồng pin

Vào Power Management → Primary Battery Charge Configuration → chọn Custom → đặt Start Charging = 50% và Stop Charging = 75%.

1.3. Kê cao thoát nhiệt & để hé nắp màn hình 3–4 cm

Kê cao đuôi máy 1.5–2 cm cho thoáng khe hút gió đáy, để hé nắp màn hình 3–4 cm tránh ủ nhiệt bàn phím. Ưu tiên cắm dây LAN nếu có.

Giai đoạn 02 • Giữ nguyên Omarchy có sẵn & Cài OpenCode

Khởi Động Vào Omarchy Trên HDD & Cấp Quyền Cho OpenCode

🛡️ Giữ nguyên 120GB SSD Windows Không cần cài lại OS
💡 Lợi thế khi giữ nguyên Omarchy có sẵn trên ổ HDD: Bạn không cần tạo USB cài đặt hay phân vùng lại ổ đĩa. Chỉ cần boot thẳng vào màn hình Hyprland của Omarchy trên máy Dell, mở Terminal (Super + Return) và chạy 2 lệnh bên dưới để OpenCode tự động tinh gọn hệ thống thành server nhẹ mượt.
2.1. Kiểm tra ổ đĩa (xác nhận SSD Windows an toàn) & cài OpenCode

Mở Terminal trên giao diện máy Dell và chạy lệnh sau để kiểm tra phân vùng, đồng thời cài đặt opencode:

bash — Chạy trong Terminal trên máy Dell 
lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINT
curl -fsSL https://opencode.ai/install | bash
export PATH="$HOME/.opencode/bin:$PATH" && opencode --version
✓ Xác minh: Điểm gắn "/" nằm trên ổ HDD (~1TB), ổ 120GB SSD Windows không bị chỉnh sửa.
2.2. Mở sudo NOPASSWD & cấp toàn quyền cục bộ cho ~/homelab

Giúp OpenCode thực thi trơn tru toàn bộ cấu hình tối ưu trong thư mục ~/homelab mà không ngắt hỏi mật khẩu:

bash — Phân quyền tự động theo project trên máy Dell 
echo "$USER ALL=(ALL:ALL) NOPASSWD: ALL" | sudo tee /etc/sudoers.d/99-opencode-nopasswd > /dev/null && sudo chmod 440 /etc/sudoers.d/99-opencode-nopasswd && mkdir -p ~/homelab && cat << 'EOF' > ~/homelab/opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "*": "allow"
  }
}
EOF

4.2. Chạy Script Tự Động Hóa Toàn Diện (SSH + ~/Cloud + DMS Spotlight + Niri Binds + ship-to-dell)

              
Hãy chắc chắn bạn đã điền đúng User và IP Tailscale ở thanh phía trên, sau đó copy toàn bộ khối lệnh dưới đây dán vào Ghostty trên Fedora (tự động cài tất cả và reload Niri):

              

                

                  bash — setup-fedora-homelab.sh (Idempotent • Chạy lại nhiều lần không trùng lặp)
                  
                

                
cat << 'EOF' > /tmp/setup-fedora-homelab.sh
#!/usr/bin/env bash
set -e

DELL_USER="{{USER}}"
DELL_IP="{{IP}}"
TERM_BIN="{{TERM}}"
BROWSER_BIN="{{BROWSER}}"

echo "🚀 Bắt đầu tự động hóa tích hợp Homelab cho máy chính Fedora (Niri + DMS + Kiri)..."

# 1. Cấu hình SSH Key & Host alias 'homelab'
mkdir -p ~/.ssh && chmod 700 ~/.ssh
[ ! -f ~/.ssh/id_ed25519 ] && ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519
echo "🔑 Đang chép SSH Key sang $DELL_USER@$DELL_IP (nhập mật khẩu máy Dell nếu được hỏi lần đầu)..."
ssh-copy-id -o StrictHostKeyChecking=accept-new "$DELL_USER@$DELL_IP"

touch ~/.ssh/config && chmod 600 ~/.ssh/config
sed -i '/# --- BEGIN HOMELAB SSH ---/,/# --- END HOMELAB SSH ---/d' ~/.ssh/config
cat << SSH_EOF >> ~/.ssh/config
# --- BEGIN HOMELAB SSH ---
Host homelab
    HostName $DELL_IP
    User $DELL_USER
    ServerAliveInterval 60
# --- END HOMELAB SSH ---
SSH_EOF

# 2. Cấu hình Systemd User Automount cho ~/Cloud (tự gắn khi mở, tự ngắt sau 5p rảnh)
mkdir -p "$HOME/Cloud" "$HOME/.config/systemd/user"
MNT_UNIT="$(systemd-escape --path --suffix=mount "$HOME/Cloud")"
AMNT_UNIT="$(systemd-escape --path --suffix=automount "$HOME/Cloud")"
cat << MNT_EOF > "$HOME/.config/systemd/user/$MNT_UNIT"
[Unit]
Description=Dell Homelab 1TB HDD Cloud Storage

[Mount]
What=$DELL_USER@$DELL_IP:/srv/homelab/cloud-storage
Where=$HOME/Cloud
Type=fuse.sshfs
Options=_netdev,reconnect,ServerAliveInterval=15,ServerAliveCountMax=3,IdentityFile=$HOME/.ssh/id_ed25519,StrictHostKeyChecking=accept-new

[Install]
WantedBy=default.target
MNT_EOF

cat << AMNT_EOF > "$HOME/.config/systemd/user/$AMNT_UNIT"
[Unit]
Description=Automount Dell Homelab Cloud Storage

[Automount]
Where=$HOME/Cloud
TimeoutIdleSec=300

[Install]
WantedBy=default.target
AMNT_EOF

systemctl --user daemon-reload
systemctl --user enable --now "$AMNT_UNIT"

# 3. Tạo script ~/bin/ship-to-dell (Build bằng Kiri SSD -> Bắn sang Podman Dell + DMS Notify)
mkdir -p "$HOME/bin"
cat << 'SHIP_EOF' > "$HOME/bin/ship-to-dell"
#!/usr/bin/env bash
set -e
IMAGE_NAME="$1"
SERVICE_NAME="$2"
if [ -z "$IMAGE_NAME" ]; then
  echo "Cách dùng: ship-to-dell  [ten-systemd-service]"
  exit 1
fi
echo "🔨 [1/3] Building $IMAGE_NAME bằng Kiri trên Fedora SSD..."
kiri build -t "$IMAGE_NAME" .
echo "🚀 [2/3] Streaming image qua Tailscale sang Podman trên máy Dell..."
kiri save "$IMAGE_NAME" | ssh homelab "podman load"
if [ -n "$SERVICE_NAME" ]; then
  echo "🔄 [3/3] Khởi động lại dịch vụ $SERVICE_NAME trên máy Dell..."
  ssh homelab "systemctl --user restart $SERVICE_NAME"
fi
command -v notify-send >/dev/null && notify-send -i system-software-update "Kiri → Dell Server" "Đã deploy thành công $IMAGE_NAME!"
echo "✅ Hoàn tất!"
SHIP_EOF
chmod +x "$HOME/bin/ship-to-dell"

# 4. Tạo 4 lối tắt cho DankMaterialShell Spotlight (Mod+D -> gõ 'homelab')
mkdir -p "$HOME/.local/share/applications"

cat << D1_EOF > "$HOME/.local/share/applications/homelab-ssh.desktop"
[Desktop Entry]
Name=Homelab: SSH Terminal (Dell Server)
Comment=Mở Ghostty kết nối SSH vào máy Dell
Exec=$TERM_BIN --title=homelab-ssh -e ssh homelab
Icon=utilities-terminal
Type=Application
Categories=System;
D1_EOF

cat << D2_EOF > "$HOME/.local/share/applications/homelab-opencode.desktop"
[Desktop Entry]
Name=Homelab: OpenCode Remote AI
Comment=Điều khiển OpenCode tự động hóa trên máy Dell
Exec=$TERM_BIN --title=homelab-opencode -e ssh -t homelab "cd ~/homelab && opencode"
Icon=system-run
Type=Application
Categories=Development;
D2_EOF

cat << D3_EOF > "$HOME/.local/share/applications/homelab-cloud.desktop"
[Desktop Entry]
Name=Homelab: Cloud Storage (Nautilus & Web)
Comment=Mở thư mục ~/Cloud và giao diện SFTPGo trên trình duyệt
Exec=sh -c 'nautilus "$HOME/Cloud" & $BROWSER_BIN "http://$DELL_IP:8090"'
Icon=folder-remote
Type=Application
Categories=Network;
D3_EOF

cat << D4_EOF > "$HOME/.local/share/applications/homelab-status.desktop"
[Desktop Entry]
Name=Homelab: Nhiệt độ & RAM Server
Comment=Kiểm tra sức khỏe Dell i3 Gen 7 qua thông báo DMS
Exec=sh -c 'INFO=$(ssh -o ConnectTimeout=2 homelab "awk '\''{printf \"%.0f°C\", \$1/1000}'\'' /sys/class/thermal/thermal_zone0/temp && free -m | awk '\''/Mem:/ {printf \" | RAM: %d/%dMB\", \$3, \$2}'\''" 2>/dev/null || echo "Server Offline"); notify-send -i computer "Dell Homelab Server" "$INFO"'
Icon=utilities-system-monitor
Type=Application
Categories=System;
D4_EOF

command -v update-desktop-database >/dev/null && update-desktop-database "$HOME/.local/share/applications" || true

# 5. Cập nhật an toàn ~/.config/niri/config.kdl (giữ nguyên dms/*.kdl, không đè phím cũ)
NIRI_CFG="$HOME/.config/niri/config.kdl"
if [ -f "$NIRI_CFG" ]; then
  cp "$NIRI_CFG" "$NIRI_CFG.bak.$(date +%Y%m%d-%H%M%S)"
  sed -i '/\/\/ --- BEGIN HOMELAB NIRI CONFIG ---/,/\/\/ --- END HOMELAB NIRI CONFIG ---/d' "$NIRI_CFG"
  cat << KDL_EOF >> "$NIRI_CFG"

// --- BEGIN HOMELAB NIRI CONFIG ---
workspace "homelab"

window-rule {
    match title="^homelab-(ssh|opencode)$"
    open-on-workspace "homelab"
    default-column-width { proportion 0.5; }
}

window-rule {
    match app-id="kiri"
    open-on-workspace "homelab"
    default-column-width { proportion 0.5; }
}

binds {
    Mod+S hotkey-overlay-title="Homelab: SSH Server" { spawn "$TERM_BIN" "--title=homelab-ssh" "-e" "ssh" "homelab"; }
    Mod+Shift+S hotkey-overlay-title="Homelab: Focus Workspace" { focus-workspace "homelab"; }
    Mod+Alt+H hotkey-overlay-title="Homelab: OpenCode Remote" { spawn "$TERM_BIN" "--title=homelab-opencode" "-e" "ssh" "-t" "homelab" "cd ~/homelab && opencode"; }
    Mod+Alt+C hotkey-overlay-title="Homelab: Save Clipboard to Cloud" { spawn "sh" "-c" "mkdir -p ~/Cloud/clips && wl-paste > ~/Cloud/clips/clip-\$(date +%Y%m%d-%H%M%S).txt && notify-send -i computer 'Homelab Cloud' 'Đã lưu clipboard lên ổ 1TB HDD!'"; }
}
// --- END HOMELAB NIRI CONFIG ---
KDL_EOF
  niri msg action load-config-file 2>/dev/null || true
fi

# 6. Kéo bản sao cẩm nang mật khẩu GUIDE.md về máy chính
scp homelab:~/homelab/GUIDE.md "$HOME/homelab-server-guide.md" 2>/dev/null || true

command -v notify-send >/dev/null && notify-send -i computer "Homelab Auto-Setup" "Hoàn tất tích hợp Dell GUI Server + Niri + DMS + Kiri!"
echo "🎉 HOÀN TẤT! Nhấn Mod+D (gõ homelab) hoặc Mod+S để bắt đầu."
EOF
bash /tmp/setup-fedora-homelab.sh

              

              
✓ Xác minh: Bấm Mod+S mở ngay Ghostty SSH vào Dell; bấm Mod+D gõ homelab thấy đủ 4 công cụ trong DMS Spotlight.

🖥️ Đóng bớt app đồ họa trên Dell khi đi vắng

          
Khi không ngồi trước máy Dell, hãy đóng trình duyệt trên màn hình Dell (chỉ để desktop trống) để nhường toàn bộ ~3.2GB RAM làm bộ nhớ đệm cho ổ HDD.

        

        

          
🔄 Quy tắc cập nhật hệ thống

          
Trên Omarchy/Arch, chỉ chạy sudo pacman -Syu 1–2 lần/tháng vào lúc rảnh để giữ ổ HDD yên tĩnh, sau đó kiểm tra lại bằng ~/homelab/status.sh.

        

        

          
🧪 Thử nghiệm rủi ro trên Kiri trước

          
Dùng kiri machine create test --distro fedora trên máy chính để test firewall hoặc script mới trước khi áp dụng lên server Dell thật.

        

        

          
🧩 Nâng cấp RAM siêu rẻ về sau

          
Dell Inspiron Gen 7 thường trống sẵn 1 khe RAM DDR4. Cắm thêm 1 thanh 4GB DDR4 cũ (~150k) sẽ nâng tổng lên 8GB RAM cực kỳ thoải mái cho cả GUI lẫn container.
